      跨设备同步

      在其他手机 / 电脑上也能更新家长查询

      在常用设备点「更新家长查询」时，会顺带把数据脱敏备份到云端（手机号转为哈希、不保留家庭住址）。
      最省事的做法：在常用设备点「生成更新链接」，把链接发到其他设备打开——令牌会自动绑定、最新数据自动载入，无需再手填令牌；改完直接点「更新家长查询」即可。

      未绑定令牌
      链接内含访问凭证，请只发给自己，勿转发他人；用完可在 GitHub 重置该令牌。
      加密云保险箱（令牌存云端，免传链接）

      在常用设备设一个主口令，把令牌加密存进公开仓库的保险箱；其他设备只需输入同一主口令即可自动绑定令牌、拉取最新数据——口令不传输、也不存云端，比发链接更省事。
